# FunLingo 🌟

> **Speak English with Unshakeable Confidence** — Complete 365-day gamified English learning platform with zero external dependencies, offline PWA capabilities, real-time speech evaluation, and native Android APK support.

---

## 🚀 Live Demo & Launch

You can host and launch FunLingo on **GitHub Pages** with zero build configuration!

1. **Web App**: Runs directly in any modern browser (`index.html`).
2. **Offline PWA**: Installable on iOS (Safari Add to Home Screen) and Android (Chrome Install App).
3. **Android APK**: Download and install [`FunLingo.apk`](./FunLingo.apk).
4. **Flutter Source**: Full Flutter project in [`funlingo_flutter_complete.zip`](./funlingo_flutter_complete.zip).

---

## ✨ Features

- 🎙️ **Real-Time Speech Recognition & Pronunciation Scoring**: Web Speech API & audio synthesis with fallback self-scoring modes.
- 🗺️ **365-Day Daily Roadmaps & Mastery Path**: Structured progression from beginner greetings to executive fluency.
- 🎮 **Gamified Micro-Learning**: XP points, daily streaks, gem rewards, and celebratory animations.
- ⚡ **Docked 3-Tier Duolingo-Style Layout**:
  - Top Bar: Instant progress tracker, lesson step indicator, and exit control.
  - Middle Area: Fluid, responsive card layout optimized across mobile, tablet, laptop, and desktop.
  - Bottom Bar: Docked **"Next ➔"** action button for seamless 1-click progression.
- 📦 **Zero External Build Tools Needed**: Single vanilla HTML/CSS/JS file (`index.html`) running at 60fps.

---

## 🛠️ Local Development

To run locally:
```bash
# Python
python -m http.server 8080

# Or Node.js
npx serve .
```
Then open `http://localhost:8080` in your browser.
